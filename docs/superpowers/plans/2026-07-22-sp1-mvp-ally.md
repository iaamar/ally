# Ally SP1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Ally MVP — a local-first accessibility-scanning MCP server (3-pass engine: static AST rules, agent-native LLM reasoning, optional Playwright runtime verification) plus a Vercel/Supabase observability dashboard with scan ingest.

**Architecture:** TypeScript pnpm/Turborepo monorepo. `@ally/shared` holds the findings contract (types + zod). `@ally/engine` implements discovery, unified JSX/HTML element model, ~24 core rules (registry designed to grow to 50), fingerprinting/clustering/prioritization, auto-fix patch generation, reasoning packets, and the Playwright+axe-core runtime pass. `@ally/mcp` wraps the engine in an MCP stdio server (8 tools, 2 prompts, 1 resource) with policy enforcement and cloud sync. `apps/web` is a Next.js App Router dashboard on Supabase (Postgres+RLS+Auth) deployed to Vercel with an API-key ingest route.

**Tech Stack:** Node ≥20, TypeScript ~5.6 (strict), pnpm 9 + Turborepo 2, vitest 3, @babel/parser+@babel/traverse (JSX/TSX), parse5 (HTML), zod 3, @modelcontextprotocol/sdk 1.x, playwright + axe-core 4.x (runtime pass), Next.js 15, @supabase/supabase-js 2 + @supabase/ssr.

## Global Constraints

- Spec of record: `docs/superpowers/specs/2026-07-22-ally-a11y-mcp-platform-design.md`. On conflict, spec wins.
- Severity enum exactly: `blocker | critical | serious | moderate | minor`. Confidence exactly: `certain | high | needs_review`. Fix classes exactly: `SAFE_AUTOFIX | SUGGEST | NEEDS_HUMAN`.
- Default conformance target **WCAG 2.2 AA** (configurable `A|AA|AAA`).
- Auto-fix NEVER writes files. Engine/MCP return `TextEdit[]` patches; the host agent applies them (visible in git diff).
- `certain`-confidence rules must have zero false positives on the clean fixture corpus (CI-enforced).
- Closed source: every package.json has `"license": "UNLICENSED"`, `"private": true` (npm publish is SP3).
- All packages ESM (`"type": "module"`). Node ≥ 20 (`engines`).
- Pass 2 is optional at runtime: engine must load and scan without playwright installed (dynamic import, friendly error).
- Dashboard must itself be accessible: semantic HTML, visible focus, labels, skip link; dogfood gate scans it in CI (Task 21).
- Conventional commits (`feat:`, `test:`, `chore:`); commit at the end of every task minimum.

## Contracts (single source of truth — later tasks must match these exactly)

`@ally/shared` exports (Task 1): types `Severity, Confidence, FixClass, Modality, SourceLocation, TextEdit, AutoFix, Finding, ReasoningPacket, Verdict, ScanSummary, ScanReport`; zod schemas `zVerdict, zScanReport, zScanIngest`; constants `SEVERITY_WEIGHT, CONFIDENCE_WEIGHT, LEVEL_ORDER, WCAG_SC`.

`@ally/engine` exports (Tasks 2–13): `scanProject(root: string, overrides?: Partial<AllyConfig>): Promise<ScanReport>`, `scanFiles(root: string, files: string[], overrides?: Partial<AllyConfig>): Promise<ScanReport>`, `applyVerdicts(report: ScanReport, verdicts: Verdict[]): ScanReport`, `collectFixes(report: ScanReport, opts: {classes: FixClass[]; fingerprints?: string[]}): AutoFix[]`, `applyEdits(source: string, edits: TextEdit[]): string`, `loadConfig(root: string): AllyConfig`, `runtimeScan(url: string, opts?: {timeoutMs?: number}): Promise<Finding[]>`, `correlate(report: ScanReport, runtime: Finding[]): ScanReport`, `RULES: Rule[]`.

`@ally/mcp`: bin `ally-mcp`; server name `ally` v `0.1.0`; tools `scan_project, scan_files, get_findings, explain_finding, get_fixes, resolve_reasoning, sync_report, configure_policy`; prompts `a11y_review_workflow, fix_no_brainers`; resource `ally://report/latest`.

Key formulas (Task 3):
- `fingerprint = sha256(`${ruleId}|${relFile}|${clusterKey}|${normSnippet}`).hex.slice(0,16)` where `normSnippet = snippet.replace(/\s+/g,' ').trim().slice(0,200)` (no line numbers → stable across shifts).
- `clusterKey` — jsx: `${relFile}#${enclosingComponent ?? tag}`; html: `${relFile}#${tag}${firstClass ? '.'+firstClass : ''}`.
- Per-finding priority = `SEVERITY_WEIGHT[severity] * CONFIDENCE_WEIGHT[confidence] * clusterCount * (requiredForTarget ? 1 : 0.3)` where `requiredForTarget = LEVEL_ORDER[finding.level] <= LEVEL_ORDER[config.targetLevel]`.
- Report score = `round(100 / (1 + weighted/max(1, filesScanned)))` where `weighted = Σ SEVERITY_WEIGHT` over non-dismissed findings.

`ally.config.json` (all optional): `{ "targetLevel": "AA", "ignoreRules": [], "ignorePaths": [], "defaultLang": "en", "autofix": "on", "appUrl": "http://localhost:3000", "projectName": "my-app" }`.

- [ ] **Step 3: Implement `parse.ts`**

Implementation requirements (write real code, no stubs):
- JSX path: `parse(source, { sourceType: 'module', plugins: ['jsx', 'typescript'] })`; traverse `JSXElement` nodes; only `JSXIdentifier` names starting lowercase become `Elem`s (custom components are skipped as elements but their names propagate: `enclosingComponent` = nearest enclosing `FunctionDeclaration` / `VariableDeclarator` id with capitalized name, else `undefined`). Attr extraction: `JSXAttribute` with `StringLiteral` → `{value, isExpression:false}`; expression containers with `StringLiteral`/template-no-subs inside → literal value; other expressions → `{value:null, isExpression:true}`; bare attr (`<input disabled>`) → `{value:null,isExpression:false}`. Name normalization map: `{ className:'class', htmlFor:'for', tabIndex:'tabindex' }` (others unchanged). `hasTextContent` = any non-whitespace `JSXText` child OR any `JSXExpressionContainer` child (assume dynamic text) OR any child element having text. `raw` = `source.slice(node.start, node.end)` of the opening element for self-closing/void; whole element otherwise, truncated to 300 chars. Locations from `node.loc` (babel is 1-based lines, 0-based cols → store cols+1).
- HTML path: `parse5.parse(source, { sourceCodeLocationInfo: true })`; walk `childNodes` recursively; element nodes → `Elem` (attrs lowercase already; `{value: attrValue, isExpression:false}`); `hasTextContent` = any descendant text node with non-whitespace; loc from `sourceCodeLocation` (already 1-based lines/cols); `raw` = `source.slice(startOffset, min(endOffset, startOffset+300))` of the start tag.
- Both: maintain `parent` pointers and push each `Elem` into `doc.elements` in document order.
